**Canyon Run** is a chase-view, pseudo-3D canyon flight game for the browser.
Thread the glowing rings in order, skim the canyon walls, and do not touch the
rock — one touch ends the run. The engine hum and ring chimes are synthesized
live with the Web Audio API; there are no audio files. The game itself is the
static bundle in `game/` (open `game/index.html` in a browser to play it
directly). Controls: arrow keys / WASD to pitch and roll, Shift / Space to
boost, P to pause, M to mute. The build is deterministic: the same input
always produces the same `out/` tree and the same `dossier.json`, byte for
byte.

## Run it

```sh
node main.ts
```
